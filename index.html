AI Native 01 · Agent Architecture

AI Continuity / 跨 Agent 上下文连续性

Context / Isolation / Handoff

当一个 Agent 的上下文或额度耗尽，下一位能接住目标、决定、开放问题和下一步，不必让用户从头解释。

关键判断
连续性需要的是可更新的最小交接状态，而不是无限复制聊天历史。
真实反转
MCP 不保证被主动调用，因此改为 CLI 主动注入、MCP 读写与回退。
交付
公开仓库、一行安装、项目隔离、接入与撤销工具；120 项测试通过。

MeetingNotes / 本地会议知识助手

Evals / Fallback / Local-first
