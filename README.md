# 莫秀文个人网站

这是一个独立的个人介绍型网站项目，和 `wechat-cc` 代码库没有代码关联。

## 本地预览

```bash
cd /Users/moxiuwen/personal-site
python3 -m http.server 3000
```

然后打开：

```text
http://localhost:3000
```
