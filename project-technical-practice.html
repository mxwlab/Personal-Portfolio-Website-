Core Question

AI 产品实践者，不能只会讲概念，也要知道工具链真实怎么工作。

我补技术不是为了把自己包装成工程师，而是为了更准确地判断：一个 AI 产品方案能不能落地， 需要哪些系统条件，工程协作中哪里是约束，哪里是可以用 AI 工具加速的空间。

Learning Map

我正在建立的工具链理解

01

网络与部署基础

从 0 搭建 VPN、理解 VPS、端口、服务启动、远程访问和本地环境之间的关系。

02

Git / GitHub 协作

理解版本、提交、分支、文件差异和协作流程，让自己能看懂工程产物怎么被推进。

03

Codex 与 Agent 工作流

用自然语言拆任务、改代码、跑预览、看截图，把 AI 从聊天工具变成真实生产工具。

04

Figma Make 与原型验证

把想法快速推进到可视化和可交互状态，再反过来训练产品表达与设计判断。

Practice Loop

我的学习方式不是收藏教程，而是围绕真实问题反复跑闭环。

遇到问题先把目标拆小，确认工具、环境、文件和输出物。

用 AI 协作让 Codex 或其他工具参与实现，但自己判断方向和结果。

验证结果跑本地预览、截图、看报错、检查移动端和实际体验。

沉淀判断把一次工具使用转成下一次产品方案里的边界感和协作语言。

What It Proves

它体现的是一种 AI Native 的工作底盘。

能下场

能转译

能持续进化

每次实践都变成下一次判断复杂 AI 产品时的经验材料。
